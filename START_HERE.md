## 🚀 Как использовать

### Быстрый старт:
1. Откройте любой шаблон раздела в `resources/views/pdf/`
2. Используйте готовые классы CSS из layout.blade.php
3. Скопируйте примеры из `STYLEGUIDE_EXAMPLES.blade.php`
4. Адаптируйте под ваши данные

### Пример использования:
```html
<!-- Раздел с метриками -->
<div class="report-section">
    <div class="report-section-title">Основные показатели</div>

    <div class="metrics-box">
        <div style="font-weight: 700; color: #1f2937; margin-bottom: 12px;">
            Итоги периода
        </div>
        <div class="metric-row">
            <span class="metric-label">Всего пользователей</span>
            <span class="metric-value">1,234</span>
        </div>
    </div>
</div>
```

## 🎓 Обучение

### Шаг 1: Понимание структуры
```
layout.blade.php содержит все стили в теге <style>
Все данные передаются через переменные $section->data()
Каждый раздел — просто HTML с CSS классами
```

### Шаг 2: Создание нового раздела
```blade
<!-- Скопируйте этот шаблон -->
<div class="report-section">
    <div class="report-section-title">Название</div>
    <!-- Добавьте содержание -->
</div>
```

### Шаг 3: Применение стилей
